# «Что изменилось» — сайт

Статическая витрина ленты нормативных изменений для учителей Казахстана.
Собирается из `feed.json`, который пишет `publish.py` из конвейера
[wonk-insights](../wonk-insights-plugin).

## Как устроено

```
insights/feed.json      ← publish.py (только записи с вердиктом clean и рецензентом)
        │  ./sync.sh
        ▼
feed.json → build.py → docs/   ← GitHub Pages отдаёт эту папку
```

Ни сборщика, ни зависимостей, ни CI: Pages настраивается на ветку `main`, папку `/docs`.

## Команды

```bash
./sync.sh              # взять свежий feed.json, пересобрать, показать diff
python3 build.py       # пересобрать из локального feed.json
```

Публикация в две руки: `sync.sh` готовит коммит, но `git push` делает человек.
Запись уезжает к учителям — это не должно происходить само.

## Что сюда НЕ попадает

Черновики, вердикты проверяющих и очередь на ревью. В `feed.json` попадают
только записи, прошедшие гейт `publish.py`: вердикт `clean`, названный рецензент,
заполненные `effective_from` и `audience`.
